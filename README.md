# Older MirageNet prototype

This folder contains an earlier standalone implementation kept for reference. Its server uses a separate SQLite database and has different APIs from the maintained project. For the current dashboard, security fixes, and supported run instructions, go to the repository root and follow [the main README](../README.md).

Avoid running `run.py` on a network you do not control. This prototype has permissive cross-origin settings and is not covered by the current root test suite.
